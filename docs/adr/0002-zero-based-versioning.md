# ADR 0002: 当面 0.x。破壊的変更もマイナー

- Status: Accepted
- Date: 2026-08-14

## Context

SemVer のメジャーは 1.0 以降の破壊的変更用。公開初期はフォルダ名や bundle ID のように、利用者環境を壊す変更が続きうる。1.0 に上げる判断は当面しない。

## Decision

バージョンは `0.x.y` のままとする。

- **マイナー**（`0.x.0`）: 機能追加、および破壊的変更
- **パッチ**（`0.0.x`）: 些細な変更

1.0 への移行は別判断。それまではメジャーを上げない。

## Consequences

- フォルダ名変更のような互換のない変更でも `0.7.0` のようにマイナーを上げる。
- パッチはバグ修正や文言・CI のような、利用者の保存物やインストール ID を変えない変更に限る。
- README の「バージョン番号」節とこの ADR を揃える。
