# ADR 0009: 表示言語は OS ロケール。アプリ内切替はしない

- Status: Superseded by [ADR 0012](./0012-in-app-language.md)
- Date: 2026-08-14

## Context

UI 文言は日本語と英語がある。設定画面や永続化した言語切替は、初期公開では優先度を下げた。

## Decision

OS の言語が日本語なら日本語、それ以外は英語。アプリ内での言語切替と永続化はしない。

## Consequences

- 英語 OS で日本語 UI にしたい、といった要望は未対応だった（#6 の追加要望）。
- 2026-08-14 以降は ADR 0012。
