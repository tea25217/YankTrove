 Yank Trove - 取扱説明書 (README)
========================================================================

Yank Trove は、YouTube 向けのデスクトップアプリケーションです。
指定したチャンネルやプレイリストから生放送アーカイブ（メン限含む）の
データ（動画・音声・チャットログ・メタデータ・字幕・サムネイル等）を
まとめて保存できます。

本アプリは YouTube 公式 API を使わず、yt-dlp を通じて公開ページや
ストリーム情報を取得します。ブラウザのクッキーを使う場合は、
ログイン中のアカウントとしてアクセスします。

【免責】
利用は自己責任です。YouTube の利用規約や法令に反する使い方、
過度な連続取得、ログイン状態での取得などにより、IP 制限、
機能制限、アカウント停止などの不利益が生じても、開発者は
責任を負いません。取得してよいコンテンツかどうか
（著作権・メンバーシップ契約を含む）も、利用者自身で判断してください。

【対応 OS】
動作確認済みは Windows です。
macOS 向けの手順は記載していますが、開発者が Mac を所持して
いないため動作未確認です。Linux は未対応です。

【配布 ID】
com.yanktrove.desktop（以前の com.yanktrove.app から変更）。
OS 上では別アプリとして扱われます。既存インストールの上書きや
設定の引き継ぎはありません。

------------------------------------------------------------------------
■ 1. 必要な環境
------------------------------------------------------------------------

【JS Runtime (Deno) - YouTube 向けの取得に必須】
Windows インストーラー版: Deno 同梱（追加作業不要）
手動インストールする場合:
  winget install DenoLand.Deno
インストール後、アプリ再起動。右上が「JS Runtime: Deno 検出済み」になること。

【FFmpeg - 動画・音声を保存するときだけ必要】
動画（MP4）や音声（MP3 / M4A）を保存するときだけ、別途インストールが
必要です。字幕・メタデータだけなら不要です。

  Windows でのインストール:
  1. Windows キーを押し「cmd」と入力して Enter（黒いウィンドウが開く）
  2. 次の1行をコピーして貼り付け、Enter:
       winget install Gyan.FFmpeg
  3. 同意を求められたら Y を押して Enter
  4. Yank Trove を一度終了し、再起動
  5. 右上が「FFmpeg: 検出済み」になれば完了

  うまくいかない場合は、PC を再起動してから 4〜5 を再試行。


------------------------------------------------------------------------
■ 2. 基本的な使い方
------------------------------------------------------------------------
1. Yank Trove を起動します。
2. 「YouTube チャンネル / プレイリスト URL」欄に URL を入力します。
   例: https://www.youtube.com/@ChannelName
   Live アーカイブのみ: https://www.youtube.com/@ChannelName/streams

3. 【メンバー限定配信を取得する場合】
   YouTube メンバーシップにログイン済みのブラウザを選択します。
   ※ Firefox 推奨。Chrome は起動中だと失敗することがあります。

4. 「取得データ選択」で保存したい項目にチェックを入れます。
   ※ 字幕は動画の原語（日本語配信→日本語）を優先取得します。

5. 「動画リストを取得」→ 動画一覧表示 → 「取得開始」


------------------------------------------------------------------------
■ 3. 保存先フォルダについて
------------------------------------------------------------------------
デフォルト: ダウンロード/YankTrove/{チャンネル名}/
「選択」ボタンで変更可能。


------------------------------------------------------------------------
■ 4. よくあるトラブル
------------------------------------------------------------------------
・Chrome クッキー失敗 → Firefox を使う / Chrome を完全終了
・n challenge solving failed → Deno をインストールして再起動
・字幕が英語 → 再取得（v0.2.0 以降は原語優先）
